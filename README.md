# An Tâm AI - Nền tảng Quản lý & Dự phóng Tài chính Cá nhân Thông minh

> "Hiểu tiền của bạn. Chuẩn bị cho tương lai."

Dự án ứng dụng trí tuệ nhân tạo hỗ trợ cá nhân hóa kế hoạch tài chính, mô phỏng rủi ro tương lai, kiểm tra thói quen chi tiêu đầu tư và đề xuất phương án bảo toàn tài sản bền vững.

## 🛠️ Công nghệ sử dụng
- **Frontend**: React SPA (Vite + TypeScript + TailwindCSS + Lucide Icons)
- **Backend**: Cloudflare Worker
- **Database**: Cloudflare D1 (SQLite trên Edge)
- **Deployment**: Cloudflare Workers Static Assets & Functions
